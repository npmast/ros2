### Turtlesim
1. 설치: DeskTop 버전은 설치가 되어 있다.
> ```py
> $ sudo apt install ros-jazzy-trutlesim
> ```
2. 설치 파일 불러오기
> ROS2 명령어를 사용하려면 새 쉘을 열 때마다 다음 명령어를 실행해야 한다.
> ``` py
> $ source /opt/ros/jazzy/setup.bash
> ```
> 2-1 쉘 시작 스크립트에 추가하기
> - 설치 파일의 불러오는 번거로움을 피하기 위해 쉘 시작 스크립트에 명령어 추가  
> ```
> $ nano ~/.bashrc
> echo "ROS2 Jazzy is now active!"
> source /opt/ros/jazzy/setup.bash
> $ source ~/.bashrc                    # 현재 쉘에 적용
> ```
> - 실행 파일 목록 확인
> ```
> $ ros2 pkg executables turtlesim
> ```
3. 터틀심 시작
> 3.1 시뮬레이터 창을 실행한다.
> ```
> $ ros2 run turtlesim turtlesim_node
> ```
> 3-2. 새 터미널을 열고 소싱한다.
> - 노드의 거북이를 제어하기 위해 새 노드를 실행한다.
> ```
> $ ros2 run turtlesim turtle_teleop_key
> ```
> 화살표 키를 누르면 거북이는 짧은 거리를 이동한 후 멈춘다.
4. rqt 사용
> ```
> $ sudo apt update
> $ sudo apt install ros-jazzy-rqt ros-jazzy-rqt-common-plugins
> $ rqt
> ```
> Plugins > Services > Service Caller 선
